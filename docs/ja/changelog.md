# 更新履歴

## v1.2.0

2026年7月31日

- **プロパティの右クリックからスライダーを追加**できるようになった。データパスをコピーせずに、その場で作成できる（[詳細](sliders.md#how-to-add)）
- **Blender 5.2.0 LTS** で動作確認。対応バージョンは引き続き 4.2 以降
- `location[0]` のように配列の先頭要素を対象にしたドライバーが、Repair で復元されない不具合を修正

***

## v1.1.0

2026年4月4日

- **Blender 4.2 以降に対応**（それまでは 5.0 専用）
- **Linked Driver** を追加。1本のスライダーで複数のプロパティを、それぞれ別の出力範囲で動かせる（[詳細](linked-driver.md)）
- Shape Key ターゲットが**カーブ・サーフェスオブジェクト**にも対応
- シェイプキーの一括追加とキーマップ表示まわりの不具合を修正
