# 更新履歴

## v1.2.0

2026年7月31日リリース

### プロパティの右クリックから追加できるようになった

操作したいプロパティを右クリックして、その場でスライダーを作れるようになった。データパスをコピーして貼り付ける手間がなくなる。

- **GUIスライダーを追加** — そのプロパティを操作する新規スライダーを作成
- **リンクGUIスライダーを追加** — 既存スライダーに連動させる Linked Driver として追加

データパスの取得に Blender 自身の機能を使っているため、マテリアルのノードツリーのように入れ子になったプロパティでも正しく指定される。**詳細設定を開く** を ON にすれば、対象プロパティを入力済みの状態で通常の Add Slider ダイアログに進める。

詳しくは [スライダーの追加方法](sliders.md#how-to-add) と [Linked Driver](linked-driver.md) を参照。

!!! note "表示条件"
    Blender 標準の右クリックメニューに **Add Driver** が表示されるプロパティでのみ表示される。

### 配列プロパティのインデックスを自動判別

Data Path ターゲットで、`location[2]` のようにパス末尾の添字からインデックスを自動で読み取るようになった。これに伴い、ダイアログから **Data Type**（Scalar / Vector）と **Array Index** の入力欄が不要になり、削除された。

インデックス 0 が誤って「自動」として扱われる不具合もあわせて修正している。

### 右クリックダイアログの改善

- コンテナ一覧の右に**選択ボタン**を追加。押すと、選んでいるコンテナがビューポート上でアクティブになる。名前だけでは判別しづらいときに使う
- **スライダー名が必須**になった。空欄のまま作成すると、以前は自動採番された名前が黙って付いていたが、警告が出るようになった
- ダイアログを開くたびに、前回入力したスライダー名や **詳細設定を開く** のチェックが残っていた問題を修正
- コンテナ欄だけ入力欄の開始位置が左にずれていた表示崩れを修正

### 動作環境

**Blender 5.2.0 LTS** で動作確認済み。5.1 / 5.2 の API 変更のうち、このアドオンに影響するものはなかった。対応バージョンは引き続き **Blender 4.2 以降**。

## v1.1.0

2026年4月4日リリース

### Blender 4.2 以降に対応

それまで Blender 5.0 専用だったが、**4.2 以降**で動作するようになった。バージョン間で仕様が変わっているボーンの表示制御と、アクションの FCurve アクセスに互換処理を入れている。

あわせて、Blender のバージョンによって使えるアイコンが違う問題（4.2 で `STRIP_COLOR` が無い、カラーアイコンの境界が 4.4 からなど）も修正した。

### Linked Driver

1本のスライダーで**複数のプロパティを同時に動かせる**ようになった。既存のスライダー（Primary）に別のプロパティを紐づけると、Primary の動きに追従して動く。プロパティごとに出力範囲を個別に設定できるため、同じ操作量で違う変化量を与えられる。

N パネルのスライダーリストで 🔗 ボタンを押すと **Manage Linked Drivers** ダイアログが開き、追加・編集・削除をまとめて行える。ターゲットに既存のドライバーがある場合は警告が出て、明示的に許可したときだけ上書きする。

詳しくは [Linked Driver](linked-driver.md) を参照。

### カーブ・サーフェスのシェイプキーに対応

Shape Key ターゲットで、メッシュに加えて**カーブオブジェクトとサーフェスオブジェクト**のシェイプキーも指定できるようになった。

### その他の修正

- Dual Controller のボーンコレクションを、実際に必要になるまで作らないようにした
- シェイプキーの一括追加で、対象オブジェクトのクリアが反映されない不具合を修正
- 同名のキーマップが複数ある環境で、プリファレンスのキーマップ表示が壊れる問題を修正
- Base Scale の説明文を分かりやすくした
