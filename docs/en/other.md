## Repair Sliders

**N Panel > GUI Tab > Panel Header Menu > Repair Sliders**

Use this when links break after renaming an object, shape key, bone, or similar target item.

Even if a slider still looks like it works after renaming, the saved connection info may still point to the old name. That can cause problems later, so run this after renaming.

This applies to **Slider**, **Joystick**, and **Dual Controller**.

### What happens when you run it

- If the saved connection info is outdated, it updates it to match the current state
- If a connection is broken but the original target still exists, it reconnects it
- If there are multiple possible matches, choose the correct one from the list and click **OK**

### How to read the dialog

| Label | Meaning |
|-------|---------|
| **All targets OK** | No issues found |
| **Repaired** | Reconnected successfully |
| **Errors** | Could not be fixed automatically. The target was deleted, or multiple matches were found and one must be chosen |

### Cases it cannot fix

- The object or bone was deleted
- The shape key was deleted
- The saved path can no longer be found

In that case, set the connection again manually.

## Reset All Transforms

**N Panel > GUI Tab > Panel Header Menu > Reset All Transforms**

Resets all slider-related bone transforms (location, rotation, scale), wire widths, color palettes, and constraint influence to their default values. This is an emergency rescue for when you cannot exit a Quick View intermediate state.

---

## Cleanup All

**N Panel > GUI Tab > Panel Header Menu > Cleanup All**

Deletes all data generated by GUI Slider at once: drivers, keyframes, bones, widget meshes, and BoneCollections. A confirmation dialog is shown before execution.

!!! note
    Bones and collections created by Dual Controller are protected and are not deleted.

## Preferences

Configure in **Edit > Preferences > Add-ons > GUI Slider**.

### Wire Width

Sets the default wire width for newly created bones. Does not affect existing bones.

Press **Apply Wire Width to All** to apply the current settings to all existing slider bones in the scene.

| Category | Setting | Default | Description |
|----------|---------|---------|-------------|
| **Slider** | Label | 1.0 | Wire width for Label bones |
| | Track | 1.75 | Wire width for Track bones |
| | Capsule Thumb | 2.5 | Wire width for Capsule style slider knobs |
| | Line Thumb | 2.5 | Wire width for Line style slider thumbs |
| **Joystick** | Circle Out | 2.0 | Wire width for outer circle bones |
| | Circle In | 2.5 | Wire width for inner circle bones |
| **Common** | Container | 1.0 | Wire width for Container bones |

### Quick View

| Setting | Description |
|---------|-------------|
| **Show Quick View Button in Header** | Shows the Quick View button in the tool header |
| **Show Color Icons in Header** | Shows highlight and mark color icons in the tool header |
| **Auto Switch to GUI Tab** | Automatically switches to the GUI tab when Quick View starts, then returns to the previous tab when it ends |

### Advanced

You usually do not need to change these settings.

| Setting | Description |
|---------|-------------|
| **Stabilize Undo/Redo** | Registers Undo/Redo handlers to help prevent crashes. Leave OFF unless you are actually seeing crashes |
